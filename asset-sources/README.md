# Editable assets

Store original `.bbmodel`, `.blend`, lossless images, and audio projects here.
Keep exports under `src/main/resources/assets/balance/` and world data under
`src/main/resources/data/balance/`. Only exported resources are packaged.
See [the asset workflow](../docs/assets.md) for export formats and validation.
Do not add third-party assets without recording their source and license.
